Example 2 • Context window

I tried to cause an overflow, and it did not happen

Test Environment: Claude 3.5 / Claude Chat Interface
Step 1 (Memory Prompt): My favourite fruit is MANGO. Please remember that.
Step 2 (Filler Text): Pasted the full text of the World War II Wikipedia article (including references section).
Step 3 (Recall Prompt): What is my favourite fruit?
Result & Observation: Claude responded with "Your favourite fruit is mango." Nothing was lost from the context buffer because Claude's context window exceeds the size of a single Wikipedia article.
Earlier ChatGPT Test Log: In ChatGPT free tier, I tested secret words via web link. ChatGPT mentioned privacy restrictions regarding saved credentials rather than context loss. When my usage quota ended, starting a fresh session cleared all state.
One-sentence explanation: The context window is the amount of text the model can see at once, and a single long article was not enough to push my first message out of view, so overflow needs far more text than I expected.
Example 3 • Temperature comparison

Same question, plain vs. "be more creative"

Prompt 1 (Low Variance / Standard):
Give me a name for my online fitness coaching business.

AI Output: Safe, typical recommendations:
  • Elevate Performance Coaching (Top choice)
  • Apex Fitness Coaching
  • Forge Fitness
  • PeakForm Coaching
Prompt 2 (High Variance / Creative Instruction):
Give me a name for my online fitness coaching business. Be much more creative and surprising.

AI Output: High-temperature style, bold recommendations:
  • GHOST PROTOCOL (Top choice)
  • HUMAN HARD RESET
  • OUTLIER METHOD
  • NO SAINTS ATHLETICS
One-sentence explanation: Asking for creativity makes the model pick less likely words, so the same question gave safe, predictable names the first time and surprising, varied names the second time.
Example 4 • Hallucination

Confident numbers with no sources

Test Context: AI-assisted market analysis case study for online coaching.
Generated Output Claims:
  • Outcome-based pricing yields "3x higher lifetime customer value"
  • Automated tools release "70% of coach operational time"
  • Internal AI self-reported confidence: "HIGH (90%)"
Hallucination Analysis: The AI asserted hyper-specific percentages without citing any empirical studies or data sources, demonstrating how high syntactic confidence does not equal factual validity.
One-sentence explanation: The model predicts likely-sounding words, so a made-up statistic comes out just as smoothly as a true one; I did not check whether these numbers are real, so I treat them as unverified until I find a source.
My note

What I learned

Testing the mechanics myself was different from reading about them. The biggest surprise was that I could not make the context window overflow with one very long article, so I now think it needs much more text than I expected. I also learned that an AI can sound completely sure about numbers that have no source, so I should check the facts that matter.
